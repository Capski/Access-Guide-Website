# Hover Content Mapping: Command Button Wizard Actions (forms.html)

**Instruksi untuk AI Code Writer:** Gunakan struktur di bawah ini untuk mengisi atribut `data-title` dan `data-desc` pada elemen *list action* di dalam *popup Command Button Wizard* halaman Forms.

## 1. Category: Record Navigation (Navigasi Data)
* **Item:** Find Next
    * **Title:** Find Next
    * **Description:** Mencari data selanjutnya yang sesuai dengan kriteria pencarian yang sebelumnya telah dimasukkan oleh user.
* **Item:** Find Record
    * **Title:** Find Record
    * **Description:** Membuka kotak dialog "Find" agar user bisa mencari data atau teks tertentu di dalam form.
* **Item:** Go To First Record
    * **Title:** Go To First Record
    * **Description:** Langsung melompat ke data (record) paling pertama yang ada di dalam tabel.
* **Item:** Go To Last Record
    * **Title:** Go To Last Record
    * **Description:** Langsung melompat ke data (record) paling akhir atau yang paling baru ditambahkan di dalam tabel.
* **Item:** Go To Next Record
    * **Title:** Go To Next Record
    * **Description:** Berpindah maju ke satu data (record) berikutnya di urutan tabel.
* **Item:** Go To Previous Record
    * **Title:** Go To Previous Record
    * **Description:** Berpindah mundur ke satu data (record) sebelumnya di urutan tabel.

## 2. Category: Record Operations (Operasi Data)
* **Item:** Add New Record
    * **Title:** Add New Record
    * **Description:** Membersihkan tampilan form dan menyiapkan baris kosong agar user bisa memasukkan data (record) baru.
* **Item:** Delete Record
    * **Title:** Delete Record
    * **Description:** Menghapus data (record) yang saat ini sedang tampil atau dipilih secara permanen dari database.
* **Item:** Duplicate Record
    * **Title:** Duplicate Record
    * **Description:** Menyalin seluruh isi data (record) yang sedang aktif untuk membuat data baru yang identik.
* **Item:** Print Record
    * **Title:** Print Record
    * **Description:** Hanya mencetak data (record) tunggal yang saat ini sedang ditampilkan di layar form ke mesin printer.
* **Item:** Save Record
    * **Title:** Save Record
    * **Description:** Menyimpan perubahan yang baru saja diketik atau diedit pada data saat ini ke dalam database.
* **Item:** Undo Record
    * **Title:** Undo Record
    * **Description:** Membatalkan ketikan atau perubahan terakhir pada data saat ini jika belum terlanjur disimpan (Save).

## 3. Category: Form Operations (Operasi Form)
* **Item:** Apply Form Filter
    * **Title:** Apply Form Filter
    * **Description:** Mengaktifkan filter pada form untuk menyembunyikan data yang tidak relevan dan hanya menampilkan data yang sesuai kriteria.
* **Item:** Close Form
    * **Title:** Close Form
    * **Description:** Menutup jendela form yang saat ini sedang aktif atau terbuka.
* **Item:** Open Form
    * **Title:** Open Form
    * **Description:** Membuka jendela form lain yang ada di dalam database. Biasanya digunakan untuk membuat menu navigasi utama.
* **Item:** Print a Form
    * **Title:** Print a Form
    * **Description:** Mencetak keseluruhan isi dari sebuah form tertentu.
* **Item:** Print Current Form
    * **Title:** Print Current Form
    * **Description:** Langsung mencetak tampilan form yang saat ini sedang aktif atau sedang digunakan oleh user.
* **Item:** Refresh Form Data
    * **Title:** Refresh Form Data
    * **Description:** Memperbarui tampilan data di form untuk memastikan user melihat data paling mutakhir (berguna jika database digunakan banyak orang bersamaan).

## 4. Category: Report Operations (Operasi Laporan)
* **Item:** Mail Report
    * **Title:** Mail Report
    * **Description:** Melampirkan laporan (report) secara otomatis ke dalam email untuk dikirim ke orang lain.
* **Item:** Open Report
    * **Title:** Open Report
    * **Description:** Membuka sebuah laporan dalam tampilan standar untuk dilihat.
* **Item:** Preview Report
    * **Title:** Preview Report
    * **Description:** Membuka laporan dalam mode *Print Preview* agar user bisa melihat persis bagaimana laporan tersebut akan tercetak di kertas.
* **Item:** Print Report
    * **Title:** Print Report
    * **Description:** Langsung mengirimkan dokumen laporan (report) ke mesin printer tanpa membuka mode *preview* terlebih dahulu.
* **Item:** Send Report to File
    * **Title:** Send Report to File
    * **Description:** Mengekspor atau menyimpan laporan menjadi format file eksternal (seperti PDF atau format teks).

## 5. Category: Application (Aplikasi)
* **Item:** Quit Application
    * **Title:** Quit Application
    * **Description:** Perintah untuk keluar dan menutup program Microsoft Access secara keseluruhan dengan aman.

## 6. Category: Miscellaneous (Lain-lain)
* **Item:** Auto Dialer
    * **Title:** Auto Dialer
    * **Description:** Memerintahkan sistem untuk secara otomatis memanggil nomor telepon yang ada di data saat ini (membutuhkan modem telepon yang terhubung).
* **Item:** Print Table
    * **Title:** Print Table
    * **Description:** Mencetak keseluruhan baris dan kolom dari sebuah tabel langsung ke printer.
* **Item:** Run Macro
    * **Title:** Run Macro
    * **Description:** Menjalankan *Macro* (kumpulan perintah otomatis) yang sudah diprogram sebelumnya di dalam database.
* **Item:** Run Query
    * **Title:** Run Query
    * **Description:** Mengeksekusi sebuah *Query*, baik untuk menampilkan hasil pencarian maupun menjalankan perintah *Update*, *Append*, atau *Delete*.
